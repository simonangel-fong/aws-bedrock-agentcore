## Tool list

  - Node.js
  - uv
  - AWS CLI
  - Git

- AgentCore CLI

---

## Install AgentCore CLI

```sh
npm install -g @aws/agentcore@1.0.3

# confirm
agentcore --version
# 1.0.3
```

---

## Install UV

- ref: https://docs.astral.sh/uv/getting-started/installation/#__tabbed_1_2

```sh
# ps
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"

# confirm
uv --version

```
